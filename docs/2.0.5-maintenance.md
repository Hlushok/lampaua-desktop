# Супровід LampaUa Desktop 2.0.5

Реліз готується після остаточного підтвердження власником 31 жовтня 2026 року.
Власник перевірив плавність проблемного 80+ ГБ 4К-торента, кадри й час на шкалі,
seek після відпускання, нерухоме наведення та приховування після виходу миші.
Попередній реліз v2.0.4 і його файли не змінюються.

## Межі Змін

- Новий desktop timeline adapter лише для seekable MPV у Windows x64.
- Один seek після mouse release, не під час drag; cancel не перемотує.
- Підказка кадру/часу, утримання панелі над шкалою через чинний API Lampa.
- Відсоток послідовно доступних pieces одного читача TorrServer із наявного
  PlayerInfo stat; за неоднозначності індикатор прихований. Не загальний прогрес
  завантаження й не нове опитування сервера.
- Приватний video-only utility process для preview, до 320x180 RGBA, 48 кадрів
  на джерело, 8 с на запит, теплий декодер до 3 с бездіяльності. D3D11 readback
  лише готової малої мініатюри; fallback ізольований від основного плеєра.
- Власна MPV DLL, її SDK/sourceParts/notices, офіційний Electron 45.0.0,
  залежності, appId, профіль і updater із 2.0.4 залишаються незмінними.
- Доступ лише до власної поточної сесії й її перевірених URL/headers; довільного
  введення URL/options через preview IPC немає. Збережено whitelist протоколів.
- Браузерний Ytdl, live IPTV, зовнішній UA Player та сервер не змінювалися.
