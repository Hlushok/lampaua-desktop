The owner requested the exact stack accepted in 1.5.24-mpv.6. Comparison against
that local build manifest confirmed identical SHA-256 values for:

- src/mpv/lampa-adapter.js
- src/mpv-runtime/renderer.js
- src/mpv-runtime/lib/main/mpv-service.js
- src/mpv-runtime/native/libmpv-2.dll

hashes. The native addon is rebuilt from the same source for that Electron ABI.
Changes enable production packaging, the ordinary profile and stable updater;
they do not replace the accepted playback routes or server modules.

## Publication Boundary

The owner explicitly approved GPL-3.0-or-later for 2.x. The prior license text is
retained under licenses/GPL-2.0-original.txt. Third-party credits and notices are
included. Complete corresponding sources for the exact prebuilt libmpv's linked
dependencies have not been verified. Therefore CI creates a DRAFT release only;
the public latest release and update channel must remain unchanged until that
source gate is complete. See release-maintenance.md.
