# LampaUa Desktop 2.0.0

Нова велика версія LampaUa: оновлений вбудований плеєр для Windows x64,
більше підтримуваних форматів відео та звуку й покращене відтворення IPTV.

## Що нового

- **Більше форматів.** Підтримка AVI/Xvid і звуку AC3/EAC3 без обов'язкового запуску окремого плеєра.
- **Звичне керування Lampa.** Пауза, перемотування, гучність, швидкість, звукові доріжки, субтитри та продовження перегляду зі збереженої позиції.
- **Виправлення IPTV.** Поліпшено відкриття каналів, які раніше завершувалися помилкою відтворення.
- **YouTube без примусового зниження якості.** Збережено перегляд у доступній для відео якості, зокрема 4K.
- **Стабільніше перемикання відео.** Покращено зупинку попереднього відтворення та відкриття наступного джерела.

Новий вбудований плеєр наразі доступний **лише у Windows x64**.
Збірки для інших платформ зберігають попередній спосіб відтворення.

## Оновлення з 1.5.24

Оновлюйте наявний додаток: ваш профіль, налаштування та вибір плеєра зберігаються.
Це стосується як звичайної версії 1.5.24, так і її збірки з AC3/EAC3.

## Чому 2.0

Змінився основний рушій вбудованого відтворення у Windows x64 та можливості
плеєра, тому це нова основна серія, а не звичайне технічне оновлення.
**1.5.24 завершує серію 1.x**, а 2.0.0 відкриває серію 2.x.
