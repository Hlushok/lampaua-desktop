# LampaUa Desktop 2.0.4

Оновлено вбудоване відеоядро MPV/FFmpeg у Windows x64 та компоненти безпеки
додатку.

- Збережено плавне відтворення великих 4К-торрентів через відеокарту.
- Збережено підтримку AVI/Xvid, H.264, HEVC, звуку AC3/EAC3, звукових доріжок
  і субтитрів у вбудованому плеєрі Windows x64.
- На macOS додано автоматичний перехід до наступної серії в IINA, якщо цю
  можливість увімкнено в налаштуваннях Lampa, та покращено повноекранний режим.
- Оновлено компоненти перевірки й отримання оновлень.

Налаштування, обліковий запис і вибір плеєра зберігаються. YouTube через yt-dlp
і далі використовує браузерний плеєр.

## Завантажити

у Windows x64; на інших платформах використовується попередній шлях відтворення.

Для Windows 32-bit і macOS 12 остання сумісна версія:
[2.0.1](https://github.com/Hlushok/lampaua-desktop/releases/tag/v2.0.1).
На цих системах автоматичне оновлення слід вимкнути в налаштуваннях.
