# LampaUa Desktop 2.0.5

Зручніше перемотування у вбудованому плеєрі Windows x64.

- Наведіть мишу на шкалу, щоб побачити кадр вибраного моменту та його час.
- Перетягуйте повзунок для пошуку сцени: відео перемотується лише після
  відпускання миші.
- Панель і прев'ю не зникають, поки курсор на шкалі, навіть якщо кадр ще
  завантажується.
- Додано індикатор буфера TorrServer, коли доступна його статистика.

Збережено плавне 4К-відтворення, звукові доріжки, субтитри, обліковий запис
і налаштування. YouTube та зовнішні плеєри працюють як раніше.
