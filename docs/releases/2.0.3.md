# LampaUa Desktop 2.0.3

Покращено плавність відтворення 4К-відео у вбудованому плеєрі Windows x64,
зокрема великих торрентів і сцен зі швидким рухом.

- Відео передається на відеокарту без зайвого копіювання кадрів через процесор.
- Виправлено перевернуте зображення та зависання керування плеєром.
- Покращено відновлення відтворення після збою графічного рушія.
- Збережено підтримку AC3/EAC3, звукових доріжок, субтитрів і позиції перегляду.

Налаштування, обліковий запис і вибір плеєра зберігаються. YouTube через yt-dlp
і далі працює через браузерний плеєр.
