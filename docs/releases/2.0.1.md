# LampaUa Desktop 2.0.1

Оновлення стабільності вбудованого плеєра для **Windows x64**.

## Що виправлено

- Усунено зависання інтерфейсу під час відтворення деяких відео, зокрема 4К, натискання паузи та перемотування.
- Увімкнено автоматичне використання апаратного декодування на сумісних відеокартах, щоб зменшити навантаження на процесор.
- Покращено закриття вікна та завершення роботи під час проблемного відтворення.

Якість відео не обмежується. Ваші налаштування, профіль і вибір плеєра зберігаються.
На інших платформах спосіб відтворення не змінено.

## Як оновитися

Скористайтеся автооновленням і перезапустіть додаток або встановіть нову версію поверх наявної.

**Windows x64:** [Встановити](https://github.com/Hlushok/lampaua-desktop/releases/download/v2.0.1/lampaua-x64-2.0.1.exe) · [Portable](https://github.com/Hlushok/lampaua-desktop/releases/download/v2.0.1/lampaua-x64-2.0.1-portable.exe)

Збірки для інших платформ доступні у файлах релізу нижче.
