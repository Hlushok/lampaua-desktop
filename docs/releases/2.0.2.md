# LampaUa Desktop 2.0.2

Оновлено основу застосунку до Electron 45 та покращено стабільність мережевих
запитів під час перегляду й роботи з TorrServer. Оновлено внутрішні компоненти.

Вбудований MPV у Windows x64, підтримка AC3/EAC3 та виправлення зависань із 2.0.1
збережені. YouTube через yt-dlp і далі працює через браузерний плеєр.
Профіль, налаштування та вибір плеєра залишаються вашими.

## Важливо перед оновленням

**Ця версія більше не підтримує Windows 32-bit і macOS 12 (Monterey).**
Потрібні Windows 10/11 x64 або ARM64, macOS 13 (Ventura) чи новіша або 64-бітний Linux.

Якщо у вас Windows 32-bit або macOS 12, **залишайтеся на
[2.0.1](https://github.com/Hlushok/lampaua-desktop/releases/tag/v2.0.1)**
та вимкніть автоматичне оновлення в налаштуваннях LampaUa. Наступні версії
вже не призначені для цих систем. Файли 2.0.1 залишаються доступними.
