# Перевірка LampaUa Desktop 2.0.1

## Межі Релізу

Користувач підтвердив усунення зависання на окремій тестовій збірці та
2026-10-21 дозволив коміт, push і публікацію. Оновлення донорів, залежностей,
Electron і MPV DLL залишені для іншого релізу.

Змінено лише обробку кадрів, асинхронне керування й завершення роботи MPV,
відповідні тести та документацію. Під час підготовки релізу встановлена
програма, робочий профіль, Lampac і серверні модулі не замінюються.

## Склад Збірки

- Версія додатка: 2.0.1; appId: com.lampaua.desktop.
- Windows x64: той самий Electron 44.4.4 AC3/EAC3 і власна MPV DLL, що у 2.0.0.
- SHA-256 MPV DLL: 5abe5c6a7714025a9af8fba34313b4fab762333f45b8d34ad13c9f220421671d.
- Windows ARM64/32-bit, Linux і macOS зберігають браузерний рушій.
- Збережені GitHub-канал оновлень, повне завантаження інсталятора та профіль.

## Перевірки До Публікації

- [x] Користувач підтвердив усунення початкового зависання.
- [x] Компіляція TypeScript, синтаксис Node, контракти MPV/UA Player/оновлень,

- [x] Після рев'ю додано очікування фонового native cleanup і скасування
      залежних команд після помилки; новий тест спочатку виявив стару поведінку,
      потім пройшов після виправлення. Native addon скомпільовано.
- [x] Повторний destroy повертає той самий збережений Promise навіть після GC.
      Прямий тест справжнього addon перевіряє 16 циклів обробки кадру й cleanup.
      Тест черги продовжує читати події після помилки: стара збірка робить один
      небажаний HTTP-запит, виправлена не робить жодного. Перевірка включена
      до кожної Windows-збірки, а остаточне рев'ю не має відкритих зауважень.
- [x] Повторний повний прогін production-пакета 2.0.1 після зауважень рев'ю.
- [ ] Чиста збірка з тегу GitHub Actions та всі пакети.
- [ ] Повторна перевірка завантаженої CI portable-збірки.
- [ ] Контрольні суми інсталяторів, метаданих оновлення й частин джерел.
- [ ] Публікація як latest і незалежна перевірка публічного каналу.

## Відтворювані Сценарії

Локальна production-збірка без встановлення пройшла:

| Перевірка                             | Свідчення         | Результат                                               |
| ------------------------------------- | ----------------- | ------------------------------------------------------- |
| Повний сценарій                       | run-1792568571336 | 51 запис результатів, код виходу 0, профіль не змінений |
| Скасування завислих мережевих запитів | run-1792568647372 | Усі сценарії пройдені                                   |
| Керування 4К                          | run-1792568662406 | 24 цикли, відгук 5-609 мс, d3d11va-copy                 |

Після 4К-тесту вікно закрилося за 295 мс, процес завершився за 774 мс.
Локальні свідчення збережені в .cache/mpv-desktop-test/evidence.

Повний сценарій перевіряє кодеки, керування, доріжки, субтитри, відновлення
позиції, маршрути YouTube/IPTV, заголовки захищених потоків і збереження профілю.
Окремо перевіряються завислі мережеві запити та 24 послідовні цикли
пауза/перемотування/відновлення на HEVC Main10 3840x2160.

Ці контрольні файли не доводять стабільність кожного стороннього потоку чи
тривалого 4К-перегляду. Підтвердження користувача стосується початкового
зависання; остаточні байти релізу перевіряються окремо після CI.
