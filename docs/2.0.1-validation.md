# Перевірка LampaUa Desktop 2.0.1

## Межі Релізу

Користувач підтвердив усунення зависання на окремій тестовій збірці та
2026-10-21 дозволив коміт, push і публікацію. Оновлення донорів, залежностей,
Electron і MPV DLL залишені для іншого релізу.

Змінено лише обробку кадрів, асинхронне керування й завершення роботи MPV,
відповідні тести та документацію. Під час підготовки релізу встановлена
програма, робочий профіль, Lampac і серверні модулі не замінюються.

## Склад Збірки

- Версія додатка: 2.0.1; appId: com.lampaua.desktop.
- Windows x64: той самий Electron 44.4.4 AC3/EAC3 і власна MPV DLL, що у 2.0.0.
- SHA-256 MPV DLL: 5abe5c6a7714025a9af8fba34313b4fab762333f45b8d34ad13c9f220421671d.
- Windows ARM64/32-bit, Linux і macOS зберігають браузерний рушій.
- Збережені GitHub-канал оновлень, повне завантаження інсталятора та профіль.

## Публічний Канал

Без авторизації GitHub перевірено latest-реліз і повний latest.yml, доступ
до SDK, обох частин джерел, інсталятора й portable та перші/останні 64 КіБ
кожного з цих п'яти файлів. Дайджести джерел відповідають зафіксованим входам.
Це не повторне повне завантаження 2,8 ГБ джерел: їхній попередній повний аудит
описаний у docs/2.0.0-validation.md, а CI повторно перевірив частини перед збіркою.

Публічний x64-інсталятор і latest.yml додатково повністю завантажені без
авторизації. Їхні розміри й SHA-256 збіглися з наведеними вище.
Окремо перевірена адреса releases/latest/download/latest.yml: вона повертає
той самий перевірений файл 2.0.1.
Свідчення: .cache/release-2.0.1-ci/verification.json,
public-access-verification.json та .cache/release-2.0.1-public/download-verification.json.

Фактичне встановлення оновлення 2.0.0 -> 2.0.1 на робочий комп'ютер користувача
чи в одноразову Windows VM не виконувалося. Перевірено готові пакети й канал
оновлень; встановлену програму не підміняли під час підготовки релізу.
