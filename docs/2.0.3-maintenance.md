# Супровід 2.0.3

## Склад і приймання

Реліз просуває перевірений D3D11 candidate `daa895b` без зміни DLL,
нативного рендерера, JS/TS-рушія або параметрів відтворення.
Змінено вибір pipeline у production-пакеті та метадані доставки.
Windows x64 отримує `lampauaMpvD3d11: true`; тестові прапорці не увімкнені.
AppId `com.lampaua.desktop`, main `src/main.js`, профіль і updater збережені.
ARM64, Linux і macOS не отримують MPV/D3D11.

Користувач підтвердив плавність попереднього проблемного 80+ ГБ
4К BDRemux протягом щонайменше трьох хвилин, включно з 25:10–25:30,
і роботу перемотування. Локальні перевірки candidate: три окремі 180-секундні
4К H264/HEVC/Main10 HDR→SDR прогони, керування, орієнтація, fullscreen,
GPU-loss fallback, повторні відкриття й завершення. Деталі та межі
вимірювань: `mpv-d3d11-performance.md`. Це не підтвердження HDR passthrough
чи фізичного scan-out кожного кадру.

## Наступні оновлення

Звичайні зміни: нова patch-версія, native addon під поточний Electron,
контракти, packaged QA, тег і чернетка workflow. Не оновлювати MPV DLL або patch
автоматично разом із JS-залежностями. Для нового MPV використати
`build-libmpv.yml` з `variant=d3d11`, повторити source/provenance/notices і GPU
перевірки, зберегти SDK та джерела перед зміною runtime pins.

`build/libmpv-d3d11-test.json` залишається записом прийнятого candidate;
`build/libmpv-runtime.json` визначає production input. Не переносити тестовий
профіль у production і не випускати пакет із `lampauaMpvTest: true`.
При втраті GPU використовується перевірений software fallback.

Попередній software runtime і джерела зберігаються в релізі/тегу `v2.0.2`.
Повернення потребує окремої нової patch-версії, без переміщення
опублікованих тегів і заміни файлів опублікованого релізу.

Порядок публікації та перевірки автооновлень: `release-maintenance.md`.

## Локальна перевірка production-пакета

IPTV, захищені HTTP-заголовки, керування, помилки, navigation recovery
і чисте закриття; metadata робочого профілю не змінились.
Раніший `run-1792768400241` перервано через неправильний шлях журналу
у самому тесті; шлях виправлено, а повний тест повторено успішно.
DLL, compiled main service і renderer bundle збігаються з останнім
прийнятим локальним тестовим пакетом. Пройшли 84 Python-тести,
JS-контракти, syntax checks, immutable Yarn install і lint.
Окреме read-only рев'ю release-promotion delta зауважень не виявило.
