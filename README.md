# LampaUa Desktop

Десктопний клієнт LampaUa для Windows, macOS і Linux.

## Серія 2.x

Версія **2.0.0** починає нову серію зі зміненою архітектурою вбудованого
відтворення. **1.5.24**, звичайна та AC3/EAC3, є останньою версією серії 1.x.

Windows x64 отримує саме протестований стек `1.5.24-mpv.6`: libmpv усередині
вікна Lampa та Electron 44.4.4 AC3/EAC3. YouTube через yt-dlp зберігає браузерний
DASH-шлях; IPTV та інші підтримувані джерела використовують MPV. Для інших
архітектур і платформ MPV у цьому релізі не заявлений.

Робочий пакет використовує чинний профіль LampaUa, не тестовий. Збережений вибір
плеєра не перезаписується. Опис змін: [CHANGELOG.md](CHANGELOG.md).

Реліз 2.0.0 готується як чернетка: публічне поширення готової libmpv DLL
потребує завершеної перевірки комплекту відповідних вихідних текстів.

## Про проєкт

LampaUa Desktop — це неофіційна адаптація десктопного клієнта `Kolovatoff/lampa-desktop` для сервера LampaUa.

Ми зробили форк оригінального проєкту, змінили назву, стартову адресу, налаштування, релізи та автооновлення, щоб застосунок був зручним для користувачів LampaUa.

Проєкт не є офіційним релізом оригінальної Lampa і не пов’язаний з авторами оригінального проєкту. Усі права на оригінальний код належать його авторам. Зміни LampaUa публікуються у відкритому репозиторії з дотриманням ліцензії оригінального проєкту.

Оригінальний проєкт: `https://github.com/Kolovatoff/lampa-desktop`

- стартова адреса за замовчуванням: `https://kinohub.uk/`;
- запасна стара адреса в налаштуваннях: `http://lampaua.mooo.com/`;
- назва застосунку: `LampaUa`;
- окремий `appId`: `com.lampaua.desktop`;
- власні артефакти збірки: `lampaua-${arch}-${version}`;
- автооновлення орієнтоване на релізи `Hlushok/lampaua-desktop`;
- вбудовані налаштування LampaUa, TorrServer, зовнішніх плеєрів, імпорту/експорту.

## Можливості

- підтримка Windows, Linux і macOS;
- синхронізація таймкодів із UA Player, VLC, KMPlayer, MPC-HC/BE і MPC-QT;
- завантаження Lampa з вибраної нової HTTPS або старої HTTP-адреси;
- експорт та імпорт конфігурації між пристроями;
- збереження позиції, розміру вікна і монітора;
- вбудована підтримка TorrServer;
- керування з геймпада Xbox, PlayStation, Switch Pro та інших контролерів зі стандартною розкладкою;
- автооновлення через релізи LampaUa.

## Реліз

GitHub Actions автоматично збирає та публікує `.exe`, `.dmg`, `.deb`, `.rpm` і `.AppImage`, коли в GitHub потрапляє тег `v*`.

Для серії 2.x workflow спочатку створює **чернетку**, яка не надходить через
автооновлення. Відкрити її як стабільний реліз можна лише після всіх перевірок.
Повний порядок, джерела компонентів, оновлення донорів і контрольні списки:
[docs/release-maintenance.md](docs/release-maintenance.md).

Для звичайного bugfix-релізу:

```bash
corepack yarn release
```

Для явного типу версії:

```bash
corepack yarn release:patch
corepack yarn release:minor
corepack yarn release:major
```

Ці команди оновлюють версію, CHANGELOG, створюють git-тег і пушать зміни на GitHub. Після пушу тега GitHub сам запускає збірку релізу.
